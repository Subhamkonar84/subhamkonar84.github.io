About

Engineering agentic systems, end to end

I'm an AI/ML engineer who builds and ships agentic AI systems and LLM-powered applications in production — not just prototypes. At 8byte, I build scalable RAG pipelines and conversational agents that retrieve context, reason over enterprise data, and execute multi-step workflows.

I deploy self-hosted LLMs with vLLM for high-throughput GPU inference, and architect distributed, fault-tolerant backends on AWS and Azure using SQS, RabbitMQ and Celery for worker-based orchestration. I own systems end to end — retrieval, memory, orchestration, automation and API/tool integrations.

Before this, I trained computer-vision models for mission-critical rail networks, built automated data-extraction pipelines, and shipped a geospatial price-prediction web app — a path that's given me range across the ML stack, from classical CV to modern LLM agents.
